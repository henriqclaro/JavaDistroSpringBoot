/04 · Arquitetura e Contrato REST

Especificação dos 4 Endpoints da API

Estrutura técnica rigorosa dos endpoints expostos pelo controlador Spring Boot e consumidos pelo front-end.

GET /distro?name={name}
200 OK · JSON Object

Consulta por nome comercial único. Retorna o objeto completo da distribuição contendo o identificador numérico interno (id) e todos os atributos.

Exemplo de Retorno: { "id": 1, "name": "Ubuntu", "base": "Debian", "environment": "GNOME", "packageManager": "apt" }
POST /distro
200 OK · Inclusão

Cadastra uma nova distribuição. Requer corpo JSON com name, base, environment e packageManager (ou package_manager).

Corpo JSON: { "name": "Fedora", "base": "independent", "environment": "GNOME", "packageManager": "dnf" }
PUT /distro?id={id}
200 OK · Atualização

Atualiza atributos de uma distribuição existente identificada pelo parâmetro numérico id. Os campos não nulos enviados no JSON sobrescrevem os valores no PostgreSQL.

Query: ?id=6 · Corpo JSON: { "name": "Debian", "base": "independent", "environment": "XFCE", "packageManager": "apt" }
DELETE /distro?name={name}
200 OK · Remoção

Remove permanentemente a distribuição com o nome passado no parâmetro de query name do banco de dados PostgreSQL.

Query: /distro?name=Ubuntu · Resposta: 200 OK sem corpo
